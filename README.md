# קירות נופלים בטיפול – דף נחיתה והרשמה

דף נחיתה ליום העיון השנתי של סקטור קרימינולוגים קליניים, המרכז לבריאות הנפש שער מנשה (7.12.2026).
ההרשמות נכתבות לגיליון Google Sheets, ולכל נרשם/ת נשלח מייל אישור.

```
index.html            הדף עצמו (HTML + CSS + JS בקובץ אחד)
assets/               לוגו, איורים, תמונת שיתוף, קובץ יומן (.ics)
apps-script/Code.gs   קוד לגיליון Google (קליטת הרשמות + מייל)
```

## שלב 1 – חיבור לגיליון Google (כ-5 דקות)

1. ליצור גיליון חדש ב-[Google Sheets](https://sheets.new), למשל בשם "הרשמות – יום עיון 2026".
2. בתפריט: **תוספים (Extensions) ← Apps Script**.
3. למחוק את התוכן שבקובץ `Code.gs`, ולהדביק את כל התוכן של `apps-script/Code.gs`.
4. (לא חובה) בראש הקובץ, ב-`CONFIG`:
   - `ORGANIZER_EMAIL` – מייל שיקבל עדכון על כל הרשמה חדשה.
   - `REPLY_TO` – לאן יגיעו תשובות של נרשמים למייל האישור.
5. לשמור (Ctrl+S). בסרגל העליון לבחור את הפונקציה **setup** וללחוץ **Run**.
   Google יבקש הרשאות: לבחור את החשבון ← **Advanced** ← **Go to … (unsafe)** ← **Allow**.
   (האזהרה מופיעה כי זה סקריפט פרטי שלך, לא אפליקציה מפורסמת.)
6. **Deploy ← New deployment** ← גלגל השיניים ← **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - ללחוץ **Deploy** ולהעתיק את ה-**Web app URL** (מסתיים ב-`/exec`).
7. בקובץ `index.html`, לחפש `PASTE_APPS_SCRIPT_WEB_APP_URL_HERE` ולהדביק במקומו את הכתובת.

> אם משנים אחר כך את `Code.gs` – צריך **Deploy ← Manage deployments ← עריכה ← Version: New version**, אחרת השינוי לא ייכנס לתוקף.

## שלב 2 – GitHub Pages

הריפו: https://github.com/yuda85/criminology

1. **Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `/ (root)` ← Save**.
2. אחרי דקה-שתיים הדף יעלה בכתובת: https://yuda85.github.io/criminology/
3. כל שינוי: `git add . && git commit -m "..." && git push` – הדף מתעדכן תוך דקה.

## שלב 3 – בדיקה

הרשמה אחת לניסיון מהטלפון: לוודא שנוספה שורה בגיליון ושהגיע מייל אישור. אחר כך למחוק את השורה.

## מה נשמר בגיליון

| עמודה | הערה |
|---|---|
| תאריך הרשמה, שם פרטי, שם משפחה, טלפון, דוא"ל, מקצוע, מקום עבודה, סטודנט/ית | מהטופס |
| תשלום | מחושב אוטומטית: סטודנט/ית או "שער מנשה" במקום העבודה ← ללא עלות; אחרת 50 ₪ |
| מייל אישור | "נשלח" או הודעת שגיאה |
| הגיע/ה | תיבת סימון לשימוש בעמדת הרישום ביום האירוע |

## מגבלות חשובות

- **מכסת מיילים:** חשבון Gmail רגיל שולח עד ~100 מיילים ביום דרך Apps Script (חשבון Workspace – ~1,500).
  אם מפעילים `ORGANIZER_EMAIL`, כל הרשמה צורכת 2 מיילים. כשהמכסה נגמרת ההרשמה עדיין נשמרת, ורק בעמודה "מייל אישור" תופיע שגיאה.
- **אחרי 7.12.2026** הטופס נסגר אוטומטית ומוצגת הודעה שההרשמה הסתיימה.
